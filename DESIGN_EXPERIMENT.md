# Experimento de diseño del portfolio

## Versiones

- `v2.0.0`: versión estable publicada.
- `experiment/ia-diseno`: evolución visual en pruebas. No sustituye a producción.

## Inventario recuperado de «IA para diseño»

### Criterio y sistema visual

- Taste Skill / `design-taste-frontend`: dirección visual y prevención de patrones genéricos.
- UI/UX Pro Max: composición, tipografía, color y espaciado.
- Web Design Guidelines e Impeccable: auditoría y refinamiento.
- Brandkit: identidad visual.
- Extract Design System: extracción de tokens desde referencias.
- Image to Code: reconstrucción de interfaces desde capturas.
- Emil Kowalski Design Skill y Design Motion Principles: criterio de interacción y movimiento.

### Construcción y animación

- 21st.dev / 21st MCP: componentes de interfaz.
- Motion for React y GSAP: transiciones y animación de interfaz.
- HyperFrames: motion graphics y vídeo generado con HTML/CSS.
- Canvas + secuencia de fotogramas + GSAP/ScrollTrigger: escenas de producto gobernadas por scroll.
- Web 3D: experiencias tridimensionales interactivas.

### Referencias y control

- Awwwards, Godly, Land-book y SiteInspire: búsqueda de referencias.
- Banana Prompts y presets visuales: generación de recursos gráficos.
- Playwright: revisión funcional, visual y responsive.
- Open Design: posible entorno general de orquestación; quedó pendiente de validación e instalación.

## Aplicación en esta V3 experimental

La web conserva el contenido y el lenguaje visual de la V2. Se han aplicado los principios que aportan valor al portfolio:

- jerarquía de entrada y revelado progresivo;
- animaciones breves ligadas a una acción o a la lectura;
- profundidad suave en el método y las tarjetas;
- microinteracciones en botones, enlaces y elementos gráficos;
- progreso de lectura;
- transición de entrada en las páginas de detalle;
- comportamiento específico para ratón, táctil y preferencias de movimiento reducido;
- ausencia de dependencias externas de animación para mantener la página ligera.

No se incluyen 3D, vídeo por fotogramas ni motion graphics. Esas técnicas encajan mejor en una página de producto y perjudicarían el peso, la lectura y el tono profesional de este portfolio.
